Evolver Architecture

Evolver Orchestrator
Central learning entity that accumulates observations from all three pipelines (Research, Review, Build). Detects patterns in findings and synthesizes change proposals for human validation.

Evolver Schemas

4 schemas support the Evolver's accumulation-to-approval lifecycle:

  • PENDING_LEARNINGS_Schema.md — Buffer for agent observations. Stores findings from Phase 2 (Accumulation_Monitor) before pattern detection.
  • CHANGE_PROPOSAL_Schema.md — Proposal format. Contains what changed, why, evidence, consumers affected, and proposed new values.
  • DEBATE_LOG_Schema.md — Human-agent interactions. Records when humans override automated decisions, approve/reject findings, or provide preference signals.
  • REVIEW_SYSTEM_CHANGELOG_Schema.md — Authoritative record of all system amendments. Entry per approved change with before/after values, approver ID, timestamp.

Evolution Cycle Flow

1. Agent Observation (All pipelines)

Agents flag findings in REVIEW_REPORT §6 (review agents) or BUILD_LOG §7 (build agents). Examples: rule gaps, threshold misalignment, schema gaps, scope conflicts.

2. Accumulation (Evolver Phase 1)

Evolver loads PENDING_LEARNINGS on every cycle. Validates entry format, organizes by source team and finding type, queues valid entries for pattern detection.

3. Pattern Detection (Evolver Phase 2)

Detects recurring themes across multiple entries. Example: If 5 reviews flag the same rule gap, pattern emerges and proposal synthesis begins.

4. Proposal Generation (Evolver Phase 3)

Creates CHANGE_PROPOSAL with evidence, impact analysis, and proposed new values. Identifies all consumers of the parameter.

5. Human Decision (Gate 1 + Gate 2)

Technical review (Gate 1) then human approval (Gate 2). Human can APPROVE, REQUEST_REVISIONS, or REJECT proposal.

6. System Update (CHANGELOG commit)

Approved change committed to System_Configuration.md, rulebook, or schema file. Logged in REVIEW_SYSTEM_CHANGELOG with full attribution.

Key Principle

The Evolver PROPOSES changes; humans DECIDE whether to commit them. The Evolver never modifies system files directly. All changes are logged in REVIEW_SYSTEM_CHANGELOG with evidence and human approver attribution.
