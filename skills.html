Layer 06 — Skills 11 user-facing entry points — thin by design, smart at entry

Skills collect inputs, invoke pipelines, return outputs. They are entry points only — they do NOT redefine pipeline logic (D27). All skills include Pre-Flight Validation — clarifying questions before pipeline entry.

Architectural Note: Skills operate as thin interfaces between users and pipelines. Each skill validates prerequisites, collects necessary context through pre-flight questions, and then routes to the appropriate pipeline. Skills maintain forward-reference-only architecture (skills → Layers 00–05, no back-references).

Configuration & Implementation Notes

  • {{CONFIG: skills.preflight_enabled}} — Global toggle for all pre-flight validation
  • preflight_confirmed: true — Flag set after user answers clarifying questions
  • Forward-reference only: Skills reference Layers 00–05 (pipeline definitions, engines, schemas, role agents, artifact flow, scoring). No back-references from pipelines to skills.
  • Deferred: evolver skill (P11, in 08_MAINTENANCE) — future enhancement for pipeline adaptation
  • Pre-Flight Pattern: All skills pause at entry, collect required context via clarifying questions, then proceed with full pipeline invocation
  • Folder Input Check (§16.1): All skill pre-flights now validate required project folders exist before pipeline invocation — {{CONFIG: paths.textbooks}}, {{CONFIG: paths.curricula}}, {{CONFIG: paths.chapters}} checked per pipeline type. On failure → user-facing remediation message with specific missing path.
  • Trigger Matching: Phrase-based detection using fuzzy matching on trigger command strings
