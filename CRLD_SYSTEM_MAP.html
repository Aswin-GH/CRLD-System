03_SCHEMAS — Next Up

03
Visual Design Schema
Hard reference in both Build engines (§2). Immutable constraint defining template zones, color system, typography, spacing. NOT generated — defined once, consumed by all builds.
03
LO_BRIEF Schema
JSON/YAML field definitions for Learning Objective Briefs. Chapter Research Engine produces these; schema validates conformance.
03
RESEARCH_BRIEF Schema
Structured schema for research briefs — required sections, §applet sub-sections, misconception format, visual model recommendations.
03
Knowledge_Ledger Schema
Defines the cumulative knowledge state data structure. All 5 engines interact with this — schema must support read + update lifecycle.
03
BUILD_SPEC / IDEAL_BLUEPRINT Schema
Design document schemas. IDEAL_BLUEPRINT = pedagogical reference; BUILD_SPEC = production specification with slide/screen-level instructions.
03
REVIEW_REPORT Schema
Output schema for review engines. Defect list, per-category scores, score band classification, RA check results, Pending_Learnings.
03
BUILD_LOG Schema
Construction record schema. Consumed by reviewers (for context) and Evolver (for pattern analysis). Separate from Debate Log.
03
Defect Code Registry Schema
Unified defect code format. Module (M-DEF-*), Applet (A-DEF-*), Contract (APPLET-*), Linguistic (LING-*). 3-tier severity.
